Polar Area Diagram — Fatalities by Type and Month

Inspired by Florence Nightingale's 1858 "Diagram of the Causes of Mortality in the Army in the East" — the pioneering chart that drove British military sanitation reform. Each wedge represents one month; radial area encodes fatalities (square-root scaled so area is proportional to deaths, exactly as Nightingale used). Overlapping colour layers show which event types dominate each month's death toll. Hover any wedge for a full breakdown.
